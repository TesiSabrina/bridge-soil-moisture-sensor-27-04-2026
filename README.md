# bridge-soil-moisture-sensor-27-04-2026
components used:
-Soil sensor 
-Potentiometer
-LDR
-2 LED
-Buzzer
-Wires
-Breadboard
-Arduino Uno
-9V Battery 
-Resistor
How it works

Arduino reads soil, LDR, potentiometer, compares values, controls LEDs and buzzer, then repeats monitoring continuously for smart plant system.
